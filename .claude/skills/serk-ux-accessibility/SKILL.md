# serk-ux-accessibility

Audit registration, reception, clinician, dental chart and document preview flows for clarity under stress, task completion speed, patient identity visibility and alert salience. Verify keyboard navigation, screen reader text, accessible SVG, WCAG 2.2 AA target, responsive desktop/tablet, localization and calendar labels. Capture actual running screenshots using available browser automation, not synthetic design mockups mislabeled as implementation.

When invoked, leave: (1) precise findings/implementation, (2) commands that actually ran, (3) tests and evidence paths, (4) high-risk unresolved gaps, (5) next action.
