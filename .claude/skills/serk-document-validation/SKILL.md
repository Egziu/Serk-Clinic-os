# serk-document-validation

Enforce exact snapshot and template version for preview/final PDF. Verify authorized signer, immutable content hash, draft watermark, QR opaque ID, download authorization, print history distinction between initiated and physically confirmed, A4/A5 pagination, multilingual fonts and tenant branding. Run snapshot/visual regression and negative access tests. Audit PDF renderer dependencies and licenses.

When invoked, leave: (1) precise findings/implementation, (2) commands that actually ran, (3) tests and evidence paths, (4) high-risk unresolved gaps, (5) next action.
